# QoS Latency Analyzer

Application Android pour l'analyse de latence et de qualité de service (QoS) réseau.

## Prérequis

- Android Studio : Hedgehog (2023.1.1) ou supérieur
- JDK : Version 8 (1.8) ou supérieur
- Android SDK : 
  - Minimum : API Level 26 (Android 8.0 Oreo)
  - Compilation : API Level 34 (Android 14)
  - Cible : API Level 34 (Android 14)
- Gradle : Version gérée automatiquement via Gradle Wrapper
